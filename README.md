# resistor

Resistor color code calculator in Rust


Resistor values are often indicated with colour codes. Practically all leaded resistors
with a power rating of up to one watt are marked with colour bands.

The coding is defined in the international standard IEC 60062. This standard describes
the marking codes for resistors and capacitors. In addition to determining the colour bands,
the standard includes numerical codes,  often used for surface-mount SMD resistors.

Several bands give the colour code. Together, they specify the resistance value, the tolerance, 
and sometimes the reliability or failure rate. The number of bands varies from three to six.
At a minimum, two bands indicate the resistance value, and one band is a multiplier. 
The resistance values are standardized and are called preferred values.s
